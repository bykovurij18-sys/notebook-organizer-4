## 📖 О проекте

**Graph Navigator** — консольное приложение для работы с графами. Поддерживает три типа графов, алгоритмы BFS/DFS, поиск кратчайшего пути (включая алгоритм Дейкстры), сохранение/загрузку в JSON и фабричное создание графов.

---

## ✨ Возможности

| Функция | Описание |
|---------|----------|
| 🏗️ Типы графов | Ориентированный, неориентированный, взвешенный |
| 📦 Паттерн Factory | Создание графов через фабрику |
| 🔍 BFS | Обход в ширину (поиск пути) |
| 🔎 DFS | Обход в глубину (поиск пути) |
| 🚀 Дейкстра | Кратчайший путь во взвешенных графах |
| 💾 JSON | Сохранение и загрузка графов |
| 🛡️ Валидация | Уникальность вершин, положительные веса |
| 🧪 Тесты | Модульное тестирование всех функций |
